# CGP-DETAILING — сайт: что добавлено и как этим пользоваться

## Что где лежит

| Файл / папка | Зачем |
| --- | --- |
| `index.html` | Сам сайт. Один файл, ничего собирать не нужно |
| `images/` | Фотографии сайта + `README.txt` со списком нужных имён |
| `favicon.ico`, `favicon-16/32/48.png` | Иконка сайта во вкладке браузера и в закладках |
| `apple-touch-icon.png` | Иконка на экране «Домой» в iPhone/iPad (180×180) |
| `icon-192.png`, `icon-512.png` | Иконки для Android и «Добавить на главный экран» |
| `site.webmanifest` | Описание сайта как приложения (название, цвета, иконки) |
| `price-template.xlsx` | Шаблон прайс-листа — импортируется в Google Таблицы |
| `cgp-site-upload.zip` | Готовый архив для загрузки на хостинг |
| `brand/` | Исходник логотипа и мастер-файл иконок |
| `preview/` | Скриншоты блоков. На сервер загружать не нужно |
| `tools/` | Служебные скрипты сборки. На сервер загружать не нужно |

      goodlab.by. Замените цены на свои: либо прямо в Google Таблице

## 2. Как выложить сайт на хостинг

Нужно загрузить в корень сайта (`public_html`, `www` или `httpdocs`):
`index.html`, папку `images` целиком, файлы иконок (`favicon.ico`,
`favicon-16x16.png`, `favicon-32x32.png`, `favicon-48x48.png`,
`apple-touch-icon.png`, `icon-192.png`, `icon-512.png`) и `site.webmanifest`.

**Вариант А — архивом (проще всего)**
1. Загрузите `cgp-site-upload.zip` в корень сайта через файловый менеджер хостинга.
2. Нажмите «Распаковать» (Extract).
3. Удалите архив с сервера.

**Вариант Б — по FTP**
1. Подключитесь к серверу любым FTP-клиентом (FileZilla, WinSCP).
2. Скопируйте в корень сайта `index.html`, `site.webmanifest`, все файлы иконок,
   а папку `images` — туда же рядом.
3. Убедитесь, что структура получилась такой:

```
/public_html/index.html
/public_html/favicon.ico
/public_html/site.webmanifest
/public_html/images/hero.jpg
/public_html/images/oklejka.jpg
...
```

**Важно про имена файлов.** Сервер на Linux различает регистр: `Hero.JPG` и `hero.jpg` —
разные файлы. Пишите имена маленькими буквами, ровно как в `images/README.txt`.

После загрузки откройте сайт и проверьте: фотографии на месте, кнопки «Записаться»
открывают форму, вкладки прайса переключаются, карта в контактах грузится.

## 3. Как подключить Google Таблицу с ценами

Прайс на сайте умеет брать цены из Google Таблицы. Заказчик правит таблицу —
сайт обновляется сам, трогать `index.html` не нужно.

**Шаг 1. Создать таблицу**
1. Откройте [Google Таблицы](https://sheets.google.com) → создайте пустую таблицу.
2. `Файл` → `Импорт` → `Загрузить` → выберите файл `price-template.xlsx`
   → «Заменить текущий лист» → `Импортировать данные`.
3. Получится два листа: `Цены` (сам прайс) и `Как заполнять` (шпаргалка).

**Шаг 2. Опубликовать в интернете**
1. `Файл` → `Поделиться` → `Опубликовать в интернете`.
2. Слева выберите лист **`Цены`**, справа формат — **CSV**.
3. Нажмите `Опубликовать` и скопируйте получившуюся ссылку.
   Она выглядит примерно так:

```
https://docs.google.com/spreadsheets/d/e/2PACX-1vXXXX/pub?gid=0&single=true&output=csv
```

**Шаг 3. Вставить ссылку в сайт**
1. Откройте `index.html` в блокноте или редакторе кода.
2. Найдите в самом начале скрипта блок `PRICE_CONFIG` и вставьте ссылку:

```js
const PRICE_CONFIG = {
    csvUrl: 'https://docs.google.com/spreadsheets/d/e/2PACX-1vXXXX/pub?gid=0&single=true&output=csv',
    cacheMinutes: 10,
    demoNotice: true
};
```

3. Сохраните файл и загрузите его на сервер (шаг 2).

Пока `csvUrl` пустой, сайт показывает встроенный прайс и серую пометку
«Прайс-лист демонстрационный». Как только ссылка вставлена, пометка исчезает,
а цены начинают приходить из таблицы.

**Если таблица недоступна** (нет интернета, ссылку отозвали, таблицу удалили) —
сайт не ломается: он показывает встроенный прайс и короткую пометку,
что цены не обновились.

`cacheMinutes: 10` — сколько минут браузер посетителя держит цены в кэше,
чтобы страница открывалась быстрее. Правки в таблице появляются
в течение этого времени.

## 4. Как заказчику менять цены и добавлять услуги

Всё делается в листе `Цены` Google Таблицы. Подробная шпаргалка лежит
в самой таблице на листе `Как заполнять`. Коротко:

| Что нужно | Что сделать |
| --- | --- |
| Изменить цену | Щёлкнуть ячейку и вписать новое значение |
| Добавить услугу | Добавить строку: повторить категорию, вписать название и цену |
| Убрать услугу | Удалить строку целиком |
| Добавить новый раздел | Написать новое название в колонке `Категория` — появится новая вкладка |
| Добавить тип авто | Вписать название в свободную колонку справа и заполнить цены |
| Задать подзаголовок раздела | Заполнить колонку `Описание раздела` в любой строке раздела |

Правила, которые стоит знать:

- **Порядок разделов** на сайте = порядок, в котором категории впервые
  встречаются в таблице сверху вниз.
- **Порядок услуг** внутри раздела = порядок строк в таблице.
- Если услуга заполнена **только в колонке `Цена`**, она попадёт в блок
  «Дополнительно» с одной ценой. Если заполнены колонки типов авто —
  она попадёт в основную таблицу.
- **Колонки без данных не показываются.** Можно спокойно добавить «Пикап»
  и заполнять его постепенно.
- Пишите либо просто число (`500` — сайт покажет «500 р.»), либо текст
  (`от 500`, `800–900`, `по запросу`) — отобразится ровно как написано.
- Колонка `Примечание` выводится мелкой серой подписью под названием услуги.

## 5. Что ещё появилось на сайте

**Раздел «Прейскурант»** (`#prices`)
Вкладки по разделам, поиск по названию услуги, таблицы с ценами по типам авто,
блок «Дополнительно» для услуг с одной ценой и кнопка записи на осмотр.
На телефоне таблицы автоматически превращаются в карточки «услуга — цена».

**Блок «Контакты»** (`#contacts`)
Телефон, мессенджеры (Telegram, Viber, WhatsApp), адрес, часы работы, соцсети,
оплата, две кнопки действия (позвонить / оставить заявку) и карта
Яндекс.Карт с адресом Монтажников 39/3.

**Навигация в шапке** — ссылки на разделы «Услуги», «Цены», «Вопросы», «Контакты».

**Заглушки вместо «сломанных» картинок.** Если файла фото нет, вместо пустого
квадрата показывается плашка «ФОТО СКОРО». Стоит проверить, что все фото
на месте: плашка = файл не найден или имя написано с ошибкой.

## 6. Иконки сайта

Иконка сделана из логотипа CGP (файл `brand/logo-source.jpg`).

| Файл | Где показывается |
| --- | --- |
| `favicon.ico` | Вкладка браузера, закладки (внутри размеры 16/32/48) |
| `favicon-16x16.png`, `favicon-32x32.png`, `favicon-48x48.png` | Вкладка и закладки в современных браузерах |
| `apple-touch-icon.png` | Ярлык на экране «Домой» в iPhone/iPad |
| `icon-192.png`, `icon-512.png` | Android и «Добавить на главный экран» |

**Почему иконка на белом фоне, а не прозрачная.** В логотипе есть и чёрные,
и белые элементы: на прозрачном фоне чёрный контур треугольника исчезал бы
на тёмной панели вкладок, а белая буква «P» — на светлой. Белая плитка
читается одинаково в любой теме браузера.

**Как пересобрать иконки** (например, из нового логотипа):

```powershell
# положите новый логотип на белом фоне в brand/logo-source.jpg
$py = "C:\Users\v.nikulshin\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"
& $py tools\build-icons.py .
```

Скрипт сам обрежет белый фон, выровняет логотип по центру и соберёт
все размеры. Если логотип будет на другом фоне — поправьте в скрипте
порог `arr > 240`.

## 7. Служебные скрипты (в папке `tools/`)

Нужны, только если захотите пересобрать шаблон таблицы после правки
встроенного прайса в `index.html`. Запускать из корня проекта:

```powershell
$node = "C:\Users\v.nikulshin\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe"
$py   = "C:\Users\v.nikulshin\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"

# 1. выгрузить встроенный прайс из index.html
& $node tools\extract-prices.js . tools\prices.json

# 2. собрать из него шаблон Excel для Google Таблиц
& $py tools\build-price-template.py .
```

`tools/build-csv-stand.py` — стенд для проверки загрузки цен:
поднимает локальный HTTP-сервер, отдаёт CSV и открывает сайт с ним,
чтобы убедиться, что таблица читается правильно.
